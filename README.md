# Інтерактивний тренажер: Закон України "Про всеукраїнський референдум" 🇺🇦

Навчальний вебдодаток, створений для інтерактивного вивчення та закріплення знань про процедуру ініціювання та проведення всеукраїнського референдуму. 

Проєкт розроблено для уроків правознавства, щоб допомогти учням легко засвоїти складні юридичні норми через інтерактивні механіки.

## 🌟 Головні можливості (Features)
*   **Інтегрований текст Закону:** Зручна бічна панель (спліт-скрин) для паралельного читання офіційного документа під час виконання завдань.
*   **Різноманітні типи завдань:** Флеш-картки, заповнення пропусків, встановлення відповідностей, вибір правильних тверджень та схем.
*   **Візуальна лінія часу (Drag & Drop):** Інтерактивне відтворення послідовності етапів референдуму за народною ініціативою.
*   **Миттєва перевірка знань:** Інтелектуальна система підсвічування правильних та неправильних відповідей.
*   **Збереження прогресу:** Усі відповіді зберігаються у браузері (Local Storage), що дозволяє не втрачати прогрес при випадковому оновленні сторінки.
*   **Адаптивний дизайн:** Коректне відображення як на ПК, так і на мобільних пристроях (Tailwind CSS).
*   **Панель успішності:** Автоматичний підрахунок результатів тестування у фінальному блоці з обчисленням відсотка засвоєння матеріалу.

## 🛠 Технології
*   HTML5
*   CSS3 (Tailwind CSS)
*   Vanilla JavaScript (ES6+)
